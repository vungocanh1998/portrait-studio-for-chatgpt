# Master roadmap

**Baseline:** V0.2.8, Gate 0 accepted on 2026-10-25.
**Next milestone:** M1 — Shared Editing Engine + White Balance.

Every item below is planned. The existing local color, crop, undo/redo, manual clone, and verified PNG export remain the supported V0.2.8 scope.

## M1 — Shared Editing Engine + White Balance — PLANNED, NEXT

- Non-destructive editing.
- Layer and mask engine.
- Extend the current color/crop session into one shared edit state and history covering layers, masks, and future tools.
- Professional color processing pipeline.
- White Balance: Auto, As Shot, Custom, Eyedropper, Temperature, Tint.

## M2 — Color Studio — PLANNED

- Advanced exposure and tone controls.
- HSL and Tone Curves.
- Creative Grading.
- Local Highlight Recovery with default strength 45%, feather 65%, and skin protection ON.

## M3 — Quality & Enhance Studio — PLANNED

- Source quality diagnostics.
- Denoise, Sharpen, Deblur, and compression repair.
- Carefully evaluated AI Upscale.
- PPI and print-size controls.
- ICC, bit depth, and export quality.

## M4 — Retouch Studio — PLANNED

- Healing, Clone, and Patch.
- Skin and Beauty Retouch.
- Digital Makeup.
- Hair and clothing cleanup.
- Healing defaults: Brush 24 px, Strength 35%, Hardness 25%.
- Texture and facial identity protection ON.

## M5 — Chat Guidance & Reference Match — PLANNED

- Select an image source in the editor.
- Optionally provide a reference image through chat.
- Analyze the reference and return actionable adjustments.
- Require user review before Apply Suggested Settings.
- Keep chat and editor state synchronized.

## M6 — Creative Lighting — PLANNED

- Golden Hour, Window Light, Backlight, and Sun Flare.
- Directional light controls and subject protection.

## M7 — Crop & Composition — PLANNED

- Advanced crop, rotate, straighten, and composition guides.
- Exact native-resolution export.

## M8 — Remote MCP — PLANNED

- Integration with ordinary ChatGPT conversations.
- Authentication and privacy controls.
- Session synchronization.
- Remote-compatible export.

Remote MCP implementation and deployment require their own security, privacy, acceptance, and owner review. No deployment is authorized by this roadmap.
