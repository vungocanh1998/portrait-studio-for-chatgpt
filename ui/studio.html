Portrait Studio for ChatGPT

A careful, local portrait-editing workspace

The original and reference pixels stay in this browser. Portrait Studio keeps only the source filename, dimensions, byte size, SHA-256, and edit history in its local MCP process so sessions can reconnect; source image bytes are never sent to MCP or ChatGPT. When you press Save edited PNG, only the finished edit is sent to the local process and saved as a new file in Downloads. “Ask ChatGPT” shares a reduced reference preview only after you press it.
